# Sacred Strings

A classical guitar trainer for worship. Guides players through a structured curriculum — from foundational chords and rhythm to confident lead playing. Built for developing worship leaders growing into lead guitar, and for beginners (especially young people in the church) building the skills to serve through music.

## Features

- **Curriculum** — A structured, 48-lesson path across three levels: Beginner's Path, Rhythm & Foundation, and Lead Guitar for Worship.
- **Music Theory** — An expandable reference covering fundamentals, scales & modes, harmony, rhythm, and worship application.
- **Practice** — An exercise library with a built-in countdown timer and completion tracking.
- **Progress** — Streaks, practice history, and per-track curriculum progress.

## Tech

- [Next.js](https://nextjs.org) (App Router) + React + TypeScript
- Tailwind CSS v4
- PWA-ready: a web app manifest and service worker so the app can be installed to an iPhone home screen ("Add to Home Screen") and feel like a native app.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Deployment

Deploys to [Vercel](https://vercel.com) with zero configuration — import the repo and deploy.
